# Lean formalisation protocol, version 2

The design and code of a protocol in which AI agents formalise mathematics in Lean: a Planner writes tasks, a deterministic Runner schedules and checks them, Provers prove them, and a Fixer repairs failed tasks.

- Start with [`docs/DESIGN.md`](docs/DESIGN.md).
- The interfaces are in [`docs/SPEC.md`](docs/SPEC.md); the decisions and their reasons in [`docs/DECISIONS.md`](docs/DECISIONS.md).
- What is built and what comes next: [`docs/BUILD_PLAN.md`](docs/BUILD_PLAN.md) and [`docs/TEST_PLAN.md`](docs/TEST_PLAN.md).
- AI agents working here: read [`AGENTS.md`](AGENTS.md) first.
